TaskNest is a modern and aesthetic To-Do List web application designed to help you organize your daily tasks with a clean, cozy, and distraction-free interface.

## ✨ Features

- ✅ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🔍 Filter tasks (All, Open, Done)
- 💾 Local Storage support (tasks remain after refresh)
- 🎨 Beautiful and responsive UI
- 📱 Works on desktop and mobile devices


2. Open the project folder

```bash

```

3. Open `index.html` in your browser.
